4

Calculate PI gains — separately for each motor

Proportional gain: Kp = (2ζωnτ − 1) / K
Integral gain: Ki = (τ × ωn²) / K
Derivative gain: Kd = 0 (PI, not PID)
Identify both motors first, then calculate the gains here.
5

Run closed-loop simulation

The PI controller compares target RPM to measured RPM, changes PWM, and repeats. Simulation uses Euler integration, PWM clamping (0–100%) and anti-windup.

Error = Target RPM − Motor RPM
PWM = clamp(Kp × Error + Ki × Integral, 0%, 100%)
Start with Step 1. Results appear below after simulation.
6

Performance metrics

These values are measured from the simulated speed response, not guessed from the gain formulas. Settling uses a ±2% band.

No simulation results yet.

How are the metrics calculated?

Overshoot (%) = max(0, (peak RPM − target RPM) / target RPM × 100).
Steady-state error (%) = |last RPM − target RPM| / target RPM × 100.
Settling time = first time after which the RPM stays inside target ±2% for the rest of the simulation.
Rise time = time from first reaching 10% to first reaching 90% of target.
Clamped PWM stays between 0% and 100%; saturation is reported separately.

7

Automatic PI tuning — if needed

If the initial simulation fails, the system automatically tests 30 Ts/ζ combinations, recalculates the PI gains for both motors, and shows the selected values. If none pass, the result remains marked as failed.

Automatic tuning runs only when the initial simulation fails.
